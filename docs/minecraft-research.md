# Minecraft 徹底リサーチ（宇宙版クローン制作のための分析）

> 目的: Minecraft のコアな仕組みを分解し、「宇宙のある惑星を舞台にしたボクセル・サンドボックスゲーム」を
> **オリジナル実装**で再現するための設計資料。Minecraft の著作物（コード・アセット・商標）は一切使用せず、
> ジャンル（ボクセル探索・建築ゲーム）として一般的な仕組みのみを参考にする。

---

## 1. Minecraft とは（概要）

- Mojang Studios が開発したサンドボックス型ボクセルゲーム。
- 世界はすべて 1m³ の「ブロック」で構成され、プレイヤーはブロックを **壊す / 置く** ことで地形を自由に改変できる。
- 明確なゴールは無く、探索・建築・サバイバル・クラフトを自由に楽しむ「サンドボックス」設計。

---

## 2. コアメカニクス（このクローンで再現する要素）

### 2.1 ボクセルワールド
- 世界は 3 次元グリッド上のブロックの集合。
- パフォーマンスのため「チャンク」（例: 16×16 の柱）単位で分割管理する。
- 描画は **面カリング**（隣接ブロックがある面は描画しない）＋チャンク単位のメッシュ結合が必須。
  愚直に 1 ブロック = 1 立方体メッシュにすると数万オブジェクトで破綻する。

### 2.2 手続き生成（Procedural Generation）
- ノイズ関数（Perlin / Simplex）で地形の高さマップを生成。
- バイオーム・鉱石・洞窟・木などを高さや別のノイズで分布させる。
- シード値で再現可能なワールドを生成。

### 2.3 ブロックの設置・破壊
- 一人称視点からの **レイキャスト** で照準先のブロックを特定（ボクセル用 DDA アルゴリズム）。
- 左クリック: 照準先ブロックを破壊。
- 右クリック: 照準先の「隣接面」に手持ちブロックを設置。

### 2.4 プレイヤー操作と物理
- 一人称視点（WASD 移動 + マウス視点、ポインターロック）。
- 重力・ジャンプ・AABB（軸並行境界ボックス）によるブロックとの衝突判定。
- クリエイティブ的な飛行モードがあると建築が快適。

### 2.5 インベントリ / ホットバー
- 画面下部のホットバーで設置するブロック種類を選択（数字キー / ホイール）。
- 本格版はクラフト・サバイバル要素を持つが、まずはクリエイティブ相当（無限ブロック）で実装。

### 2.6 見た目・アート
- 16×16 ピクセルの低解像度テクスチャを各ブロック面に貼る独特のブロック美学。
- フィルタは Nearest（ニアレストネイバー）でドット感を維持。

## 3. ゲームモード（参考）
| モード | 内容 |
| --- | --- |
| クリエイティブ | 無限ブロック・飛行可・無敵。建築向け。 |
| サバイバル | 資源採取・体力・空腹・敵 (Mob)。 |
| その他 | ハードコア / アドベンチャー / スペクテイター 等。 |

→ 本クローンは **クリエイティブ相当** から実装し、宇宙テーマを加える。

---

## 4. 宇宙版へのアレンジ（オリジナル要素）

Minecraft の仕組みを下敷きに、舞台を「遠い惑星」に置き換える。

- **舞台**: 異星（エイリアンプラネット）の地表。
- **重力**: 地球より低い低重力。ジャンプが高く、滞空が長い。
- **空**: 星空（スターフィールド）、太陽、遠くに浮かぶ惑星・衛星。
- **ブロック**: 地球の草・土ではなく、異星の地表素材に置き換える。
  - エイリアン地表 (alien grass) / レゴリス土 (dirt) / 岩盤 (rock)
  - 発光クリスタル (crystal) / 氷 (ice) / 砂・レゴリス (regolith)
  - 鉱石 (ore) / 岩盤底 (bedrock) / 発光鉱脈 (glow)
  - 異星樹の幹 (trunk) / 異星樹の葉 (alien leaves)
- **演出**: 暗い宇宙背景、発光ブロック、フォグで遠景をぼかす。

## 5. 技術設計（このリポジトリでの実装方針）

- **描画**: Three.js（WebGL）。CDN から ES Module で読み込み、ビルド不要で動作。
- **構成**:
  - `space-craft/index.html` — エントリ（importmap で three を読み込み）
  - `space-craft/src/noise.js` — Perlin ノイズ（地形生成）
  - `space-craft/src/textures.js` — 手続き生成のテクスチャアトラス（オリジナル・ドット絵）
  - `space-craft/src/blocks.js` — ブロック定義（面ごとのテクスチャ・属性）
  - `space-craft/src/world.js` — チャンク管理・地形生成・メッシュ生成・面カリング
  - `space-craft/src/player.js` — 一人称操作・物理・衝突
  - `space-craft/src/sky.js` — 星空・太陽・遠景の惑星
  - `space-craft/src/ui.js` — クロスヘア・ホットバー・操作説明
  - `space-craft/src/main.js` — ループとレイキャスト（設置/破壊）の統合
- **パフォーマンス**: チャンク単位のメッシュ結合 + 露出面のみ描画 + フォグ + 描画距離制限。

## 6. 操作仕様（実装する内容）

| 操作 | キー / マウス |
| --- | --- |
| 移動 | W / A / S / D |
| 視点 | マウス（クリックでポインターロック） |
| ジャンプ | Space |
| 飛行モード切替 | F |
| 飛行中の上昇 / 下降 | Space / Shift |
| ブロック破壊 | 左クリック |
| ブロック設置 | 右クリック |
| ブロック選択 | 数字キー 1〜9 / マウスホイール |

- テクスチャはすべて実行時に手続き生成（オリジナル）。
